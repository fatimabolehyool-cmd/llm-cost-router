# Experiment 3: router container → Ollama vs host → Ollama

All figures measured on this Mac; none are estimates. Same request in every series;
`ping` = `GET /api/version` (network hop only); `chat` = one junior-style call (hop + model time).

| Series | Reachable | Ping p50 ms | Ping p95 ms | Chat p50 ms | Chat p95 ms | Errors |
|---|---|---|---|---|---|---|
| host_a | yes | 0.20 | 0.25 | 101 | 101 | 0 |
| container | yes | 0.26 | 0.33 | 102 | 103 | 0 |
| host_b | yes | 0.20 | 0.25 | 101 | 101 | 0 |

**Overhead of the container path** (container minus the mean of the host series):

- ping p50: +0.06 ms
- ping p95: +0.08 ms
- chat p50: +1.23 ms
- chat p95: +1.43 ms

Context: the junior timeout is 8,000 ms (I3) and the routing-overhead budget is 200 ms p95 (NFR). Two host series bracket the container series, so a large gap between them would indicate thermal drift rather than a network effect.
