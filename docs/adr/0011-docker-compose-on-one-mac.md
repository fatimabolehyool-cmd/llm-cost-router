# ADR-11: Docker Compose on one Mac

**Status:** Accepted, implemented. **Date:** 24 Oct 2026 (architecture deliverable).

## Decision

All services run with Docker Compose on one Mac, with profiles per stage.

## Alternatives considered

Kubernetes or kind.

## Reason and evidence

One host needs no cluster orchestration; time and hardware. The professor allowed the proposal to be amended (24 Oct).
