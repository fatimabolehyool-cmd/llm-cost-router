# ADR-19: Scalability claimed for one Mac only

**Status:** Accepted. **Date:** 24 Oct 2026 (architecture deliverable).

## Decision

Scalability is claimed and measured for one Mac only.

## Alternatives considered

Cloud-scale claims.

## Reason and evidence

E1b: about 1.2 requests per second. The router is stateless and could scale out, but that is not built.
