# ADR-18: No Vercel; the router serves the demo page

**Status:** Accepted, implemented. **Date:** 24 Oct 2026 (architecture deliverable).

## Decision

The demo page is a static page served by the router.

## Alternatives considered

A Vercel page or functions.

## Reason and evidence

A hosted page could not reach a router running on the Mac.

## As built

See ADR-34 for its content security policy.
